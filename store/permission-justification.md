# Обоснование разрешений для RuStore

В манифесте объявлено одно разрешение — `android.permission.RECORD_AUDIO`.
`INTERNET` и другие сетевые разрешения отсутствуют, поэтому приложение
физически не может отправить запись или статистику на сервер.

## Текст в поле «Обоснование» для RECORD_AUDIO

Можно вставить в RuStore Консоль как есть:

```
Микрофон нужен только для необязательного режима «Эхо» — упражнения на
звукоподражание для детей 1,5–4 лет. Ребёнок слушает голос животного,
повторяет звук и сразу слышит свою запись, чтобы сравнить.

Как это устроено:
1. Режим «Эхо» по умолчанию выключен. Его включает родитель в экране
   «Родителям», который открывается тремя быстрыми нажатиями по замку.
2. При первом запуске записи приложение сначала показывает объяснение:
   зачем микрофон, сколько длится запись и что она не покидает устройство.
   Системный запрос разрешения появляется только после нажатия
   «Разрешить микрофон».
3. Запись длится не более 5 секунд, сохраняется в кэш приложения
   (cacheDir) и воспроизводится сразу после остановки.
4. Запись удаляется при закрытии окна «Эхо». Если процесс завершился
   аварийно, временные файлы удаляются при следующем запуске приложения.
5. При выключении режима временные записи удаляются сразу. На Android 13+
   приложение отзывает доступ к микрофону автоматически после закрытия
   приложения; на Android 8–12 разрешение можно отозвать в настройках.
6. Без разрешения на микрофон приложение полностью работает: доступно
   прослушивание звуков животных и вся игра.

Аудио не отправляется на серверы, не используется для распознавания речи,
не связывается с ребёнком или устройством и не передаётся третьим лицам.
В приложении нет рекламы, аналитики и аккаунтов. Разрешение INTERNET
не запрашивается.
```

## Ответы в блоке «Безопасность данных»

| Вопрос | Ответ |
| --- | --- |
| Приложение собирает данные пользователей? | Нет |
| Аудиозаписи передаются за пределы устройства? | Нет |
| Аудио используется для рекламы или аналитики? | Нет |
| Есть сторонние SDK, собирающие данные? | Нет |
| Пользователь может удалить данные? | Да: «Сбросить прогресс» в родительской панели или очистка данных приложения |
| Нужен аккаунт? | Нет |

Если Консоль просит отметить «Аудио» в категориях данных, выбирайте
вариант «не собирается / обрабатывается только на устройстве», если такой
вариант доступен. Если формулировка требует указать обработку, добавьте
комментарий: «Аудио обрабатывается локально и удаляется после закрытия
режима; передачи нет».

## Что проверить перед отправкой на модерацию

- [x] В карточке версии указано обоснование `RECORD_AUDIO` — текст ниже,
      копируется в поле целиком.
- [x] В приложении действительно нет `INTERNET` (проверить в APK/AAB) —
      проверено 25.11.2026: `aapt2 dump badging app-release.apk` показывает
      только `RECORD_AUDIO` и служебное
      `ru.tac.whosayswhat.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION`;
      в `base/manifest/AndroidManifest.xml` собранного AAB `INTERNET`
      не встречается ни разу.
- [x] Экран объяснения появляется **до** системного диалога разрешения —
      проверено по коду: `ui/EchoDialog.kt` показывает объяснение, и только
      кнопка «Разрешить микрофон» вызывает `permissionLauncher.launch(...)`.
- [x] Отказ от разрешения не блокирует игру — проверено по коду: песочница,
      игра и награда не обращаются к `RECORD_AUDIO`, режим «Эхо» просто
      остаётся недоступен.
- [ ] В описании и политике конфиденциальности одинаковые формулировки:
      «до 5 секунд», «cacheDir/временная папка», «удаляется при закрытии
      окна», «INTERNET не запрашивается» — сверить перед публикацией
      (`store/listing-ru.md`, `store/privacy-policy.md`).
- [x] Тестовый сценарий для модератора приложен — см. ниже и блок
      «Комментарий для модератора».

## Тестовый сценарий для модератора

1. Запустить приложение. Убедиться, что игра работает без запросов
   разрешений: нажать на животных в песочнице, затем «Играть».
2. На главном экране трижды быстро нажать на замок в правом верхнем углу.
3. В панели «Родителям» включить «Режим „Эхо“», при желании выбрать
   конкретное животное для упражнения и закрыть панель.
4. Нажать кнопку с микрофоном рядом с «Играть».
5. Убедиться, что сначала показано объяснение «Зачем микрофон?».
6. Нажать «Разрешить микрофон», выдать разрешение.
7. Нажать «Записать голос», произнести звук, нажать «Стоп».
8. Услышать запись, нажать «Записать снова» или «Готово».
9. Закрыть окно и проверить в настройках приложения, что разрешение можно
   отозвать; после отзыва запись недоступна, но игра работает.
10. Снова открыть панель «Родителям», выключить «Режим „Эхо“» и убедиться,
    что появилось объяснение про удаление записей и отзыв доступа.

Детская офлайн-игра для запуска речи: животные, их голоса и режим «Эхо».

ЗАЧЕМ МИКРОФОН
Единственное пользовательское разрешение — RECORD_AUDIO. Оно нужно только

ru.tac.whosayswhat.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION — служебное:
его автоматически добавляет библиотека AndroidX для безопасной доставки
системных сообщений внутри приложения. Оно не запрашивается у пользователя
и не даёт доступа к данным.
Разрешения INTERNET нет: приложение физически не может отправить запись,
прогресс или статистику на сервер.

2. Запись длится не более 5 секунд, сохраняется в cacheDir приложения,

4. Отказ от разрешения ничего не блокирует: песочница, игра, награда и

5. На Android 13+ доступ к микрофону отзывается автоматически после
   закрытия приложения, когда «Эхо» выключено; на Android 8–12 разрешение
