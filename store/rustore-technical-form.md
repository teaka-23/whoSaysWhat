# Технические сведения версии в RuStore

Готовые значения для блока «Технические сведения» в форме «Загрузка версии
приложения» (шаг после загрузки APK). Зафиксировано для версии 0.3.1
(`versionCode 4`); проверено по коду, манифесту и собранным APK/AAB.

Официальные правила:

- «Как декларировать разрешения» —
  `/help/developers/publishing-and-verifying-apps/app-publication/new-version-app/declare-app-permissions/how-to-declare-permissions`
- «Категории и типы данных» —
  `/help/developers/publishing-and-verifying-apps/app-publication/new-version-app/declare-app-permissions/data-categories`

## Запрашиваемые данные

| Поле | Значение |
| --- | --- |
| Типы данных | **Аудиозаписи и голосовые сообщения** (1 из 38) |
| Другие типы | не выбирать |

Почему так: консоль сама добавляет типы данных, соответствующие разрешениям
из манифеста («Автоматическое заполнение списка» в справке). У приложения
единственное пользовательское разрешение — `RECORD_AUDIO`, поэтому
«Аудиозаписи и голосовые сообщения» подставлены автоматически. Убирать этот
тип не нужно: иначе останется разрешение на микрофон без заявленных данных,
и модератор задаст вопрос. Данные при этом не покидают устройство — это
прямо сказано в обосновании: нет `INTERNET`, запись удаляется при закрытии
окна.

Типы вроде «Взаимодействие с приложением» не заявляем: прогресс и настройки
хранятся только в локальном `DataStore`, никуда не передаются и не
собираются сервером.

## Чувствительные разрешения

| Поле | Значение |
| --- | --- |
| Разрешение | `RECORD_AUDIO` (подставлено автоматически) |
| Обоснование | текст на 174 символа из `store/permission-justification.md` |

Копировать из раздела «Сообщение в поле „Комментарий для модератора“»
(лимит поля — 180 символов, длина закреплена `tools/check_moderator_note.py`):

```
Микрофон нужен лишь режиму «Эхо» (по умолчанию выключен): ребёнок повторяет звук и слышит запись. До 5 с в кэше, удаляется при закрытии окна, в сеть не уходит (INTERNET нет).
```

## Интеграции

| Поле | Значение |
| --- | --- |
| Платёжные | не выбрано |
| Рекламные | не выбрано |

Почему: в зависимостях только AndroidX/Compose и `kotlinx.serialization`,
нет ни billing, ни одной рекламной библиотеки; в манифесте нет `INTERNET`,
поэтому реклама и платежи физически невозможны.

## Требования к устройству

| Поле | Значение |
| --- | --- |
| Минимальная версия Android | **8** (`minSdk = 26`, то есть Android 8.0) |

Телефон и планшет поддерживаются, отдельной ТВ-версии нет.

## Если модератор задаст вопрос

- **«Почему заявлены аудиозаписи, если данные не передаются?»** — тип данных
  подставлен консолью из разрешения `RECORD_AUDIO`; запись обрабатывается
  только на устройстве, приложение не имеет `INTERNET` и удаляет файл при
  закрытии окна «Эхо».
- **«Зачем микрофон, если игра работает без него?»** — микрофон нужен только
  необязательному режиму «Эхо» для занятий с ребёнком; режим выключен по
  умолчанию, включается в панели «Родителям», а объяснение показывается
  раньше системного диалога.

## Порядок заполнения

1. Загрузить `app/build/outputs/apk/release/app-release.apk` (0.3.1,
   `versionCode 4`).
2. Проверить, что в «Типы данных» остался только один тип — «Аудиозаписи и
   голосовые сообщения».
3. Вставить обоснование для `RECORD_AUDIO` (174 символа выше).
4. Оставить пустыми «Платёжные» и «Рекламные» интеграции.
5. Проверить минимальную версию Android — 8.
6. «Что нового» взять из `store/listing-ru.md`, описание — оттуда же.
7. Отправить на модерацию.
