# Навыки Cline

Здесь лежат адаптированные навыки из репозитория
[mattpocock/skills](https://github.com/mattpocock/skills). Они помогают
проектировать фичи, уточнять требования, вести глоссарий и ADR, писать тесты
и делать ревью. Навыки — это инструкции для агента, а не код приложения:
Gradle их не видит, на APK/AAB они не влияют.

Пакет нейтральный: в `SKILL.md` нет путей и терминов конкретного проекта.
Проектный контекст живёт в `.clinerules`, `docs/agents/project-context.md`,
`GLOSSARY.md` и `docs/adr/`, а навык читает эти файлы, если они есть.

## Источник

- Репозиторий: `https://github.com/mattpocock/skills`
- Закреплённый коммит: `6f7f7831a625f040a8e06a0e7954826b87ce775a`
- Лицензия: MIT, копия — в `LICENSE`.

Отличия от upstream:

- `grill-me` вызывает `grilling` чтением соседнего файла `grilling/SKILL.md`,
  а не через Claude-специфичный `Skill tool`.
- В начало `SKILL.md` добавлен нейтральный блок «Project context»: найти
  `.clinerules`, `AGENTS.md`, `docs/agents/project-context.md`, `GLOSSARY.md`,
  ADR и фактические команды проекта. Правила проекта важнее навыка.
- `handoff` ссылается на навыки относительно корня навыков
  (`grilling/SKILL.md`), а не абсолютными путями.
- Убраны Claude-специфичные поля frontmatter `argument-hint` и
  `disable-model-invocation`.

## Что установлено

`grill-me` — тонкая обёртка над `grilling`, поэтому каталогов восемь, а
логических навыков семь.

| Навык | Роль |
| --- | --- |
| `grilling` | Допрос по дереву решений: требования, границы, риски |
| `grill-me` | Явный запуск `grilling` командой `/grill-me` |
| `codebase-design` | Глубокие модули, интерфейсы, швы и тестируемость |
| `domain-modeling` | `GLOSSARY.md` и ADR |
| `tdd` | Red-green-refactor |
| `diagnosing-bugs` | Диагностика сложных багов через обратную связь |
| `code-review` | Ревью diff по стандартам и по спеке |
| `handoff` | Компактная передача контекста следующей сессии |

## Глобальная копия

Тот же нейтральный пакет установлен в `~/.cline/skills/`, чтобы навыки были
доступны в других проектах. Cline 4.1.27 также читает `~/.agents/skills/`.
Источник истины — этот каталог; глобальная копия синхронизируется скриптом:

```bash
./tools/sync_global_skills.sh
```

Скрипт копирует навыки и `LICENSE`, не удаляя посторонние навыки в
`~/.cline/skills/`. README глобальной копии берётся из
`docs/agents/global-skills-README.md`.

Локальная и глобальная копии должны совпадать. Cline сканирует сначала
проектные каталоги, затем глобальные; при одинаковом id глобальная запись
может перекрыть проектную. Пока содержимое идентично, это безопасно; если
правите навык, сразу синхронизируйте копию. Проектные особенности добавляйте
в `.clinerules` и `docs/agents/project-context.md`, а не в `SKILL.md`.

## Как обновлять

1. Склонируйте upstream во временный каталог и зафиксируйте коммит.
2. Перенесите только нужные каталоги, сохранив вложенные `*.md` и
   `agents/openai.yaml`.
3. Сохраните нейтральный блок «Project context» и адаптацию `grill-me`.
4. Проверьте frontmatter: `name` совпадает с каталогом, `description` короче
   1024 символов, нет полей, которые не понимает Cline core.
5. Обновите коммит и список изменений в этом файле, в
   `docs/agents/global-skills-README.md` и в ADR
   `docs/adr/0001-use-agent-skills.md`.
6. Выполните `./tools/sync_global_skills.sh`.

Перед обновлением проверьте, что Cline видит навыки в меню Skills и по `/`.
