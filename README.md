# Кто как говорит? — Android-приложение

Нативное приложение по `kto_kak_govorit_design_doc.md`: спокойная детская
игра для запуска речи. Двадцать два животных с иллюстрациями и звуками,
**крупный план** по тапу, игра «Угадай», родительская панель с прогрессом и
необязательный режим «Эхо». Работает офлайн, без рекламы, аналитики и
аккаунтов.

## Стек

| Слой | Решение |
| --- | --- |
| Язык / UI | Kotlin 2.0.21, Jetpack Compose, Material 3 |
| Сборка | Gradle 8.9, AGP 8.7.3, version catalog |
| minSdk / target | 26 / 35 (Android 8.0 … 15) |
| Контент | `assets/catalog.json` + kotlinx.serialization |
| Звук | `SoundPool` + `AudioFocus`, всё в APK |
| Прогресс | DataStore Preferences |
| Разрешения | `RECORD_AUDIO` — только для необязательного режима «Эхо»; `INTERNET` отсутствует |

## Сборка

Нужны JDK 17+ (проверено на Temurin 21) и Android SDK: `platforms;android-35`,
`build-tools;35.0.0`, `platform-tools`.

```bash
export JAVA_HOME=$HOME/jdk/jdk-21.0.13.1+2/Contents/Home
export ANDROID_HOME=$HOME/android-sdk
echo "sdk.dir=$ANDROID_HOME" > local.properties

./gradlew testDebugUnitTest     # unit-тесты логики и каталога
./gradlew lintDebug             # отчёт: app/build/reports/lint-results-debug.html
./gradlew assembleDebug         # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease       # подписанный APK (при наличии keystore.properties)
./gradlew bundleRelease         # AAB для RuStore
```

GitHub Actions (`.github/workflows/android.yml`) на каждый push в `main` и на
pull request прогоняет `testDebugUnitTest`, `lintDebug` и `assembleRelease`.
Без `keystore.properties` релизная сборка в CI неподписанная — проверяются
только R8 и shrinkResources.

`RECORD_AUDIO` запрашивается только после объяснения и явного нажатия
«Разрешить микрофон»; без него игра работает полностью. AndroidX добавляет
в манифест signature-level разрешение
`ru.tac.whosayswhat.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` для внутренних
receiver'ов — оно не показывается пользователю и не запрашивается в рантайме.

Подпись: скопируйте `keystore.properties.example` в `keystore.properties`,
положите `release.keystore` в корень проекта. Оба файла в `.gitignore`.

## Что уже работает

- **Песочница**: 22 животных с авторскими иллюстрациями, тап по карточке →
  звук; после звука — короткая пауза и тёплая фраза «Это слоник!» — медленно,
  почти по слогам, чтобы ребёнок запоминал связку «образ — звук — слово».
  Ласковое имя берётся из `affectionate_name`, а на карточках остаётся
  обычное «Слон» (озвучивает системный синтезатор речи, интернет не нужен);
  крупные зоны нажатия, 2 колонки на телефоне и больше на планшете,
  прокрутка; верхний отступ не пересекается с кнопкой «Выйти» и замком.
- **Крупный план**: тот же тап открывает увеличенную иллюстрацию с названием
  и звукоподражанием («Му-у-у!»). Окно не обрывает звук: оно закрывается
  само, когда договорила озвучка названия, но висит не меньше 2,5 с, чтобы
  короткое «Мяу!» не мигало. Повторный тап по картинке повторяет звук,
  Back и тап по затемнённому фону возвращают в песочницу.
- **Игра «Угадай»**: 5 правильных ответов до награды; 2/3/4 карточки
  (родительская настройка); сетка 2×N подстраивается под высоту экрана без
  прокрутки; звук повторяется автоматически и по кнопке; ошибка не
  наказывает — карточка качается, раунд продолжается.
- **Без повторов**: правильный ответ не выпадает два раза подряд, позиция
  балансируется, набор карточек меняется.
- **Награда**: короткое конфетти + «Молодец!» и звуковая похвала.
- **Прогресс**: сессии, верные ответы и звёзды по каждому животному в
  DataStore; сброс в родительской панели.
- **Родительский гейт**: три быстрых нажатия по замку (без математики),
  панель с уровнем, режимом «Эхо», выбором животного для «Эхо», сбросом
  прогресса и блоком «Приватность». Back панель не открывает — только гейт;
  на главном экране Back не делает ничего.
- **Выход**: приглушённая кнопка «Выйти» в левом верхнем углу песочницы —
  один тап и подтверждение («Выйти» / «Остаться»), чтобы ребёнок не закрыл
  игру случайно; та же кнопка есть в шапке панели родителей.
- **Режим «Эхо»**: объяснение до системного разрешения, запись до 5 секунд,
  воспроизведение, удаление файла при закрытии окна и при выключении режима.
  Если процесс завершился аварийно, временные файлы очищаются при следующем
  запуске. На Android 13+ выключение режима отзывает доступ к микрофону после
  закрытия приложения; на Android 8–12 доступ отзывается в настройках.
  Запись не покидает устройство.
- **Выбор животного для «Эхо»**: в родительской панели можно закрепить
  конкретное животное; по умолчанию используется последнее нажатое.
- **Приватность**: нет `INTERNET`, рекламы, аналитики и аккаунтов. Названия
  животных произносит системный синтезатор речи — приложение само ничего
  не отправляет и не хранит.
- **Киоск-режим**: экран не гаснет, системные панели скрыты.
- **Доступность**: TalkBack называет животное отдельно от действия
  («Корова», «Выбрать»), исход раунда объявляется сам через live region
  («Верно» / «Не то, попробуй ещё»), а эмодзи-украшения не читаются.
- **Память**: декодированные иллюстрации живут в `LruCache` (восьмая часть
  кучи, 8…64 МБ), поэтому прокрутка песочницы не декодирует PNG заново.

## Тесты

`SessionEngineTest` проверяет состав раунда, отсутствие повторов правильного
ответа, баланс позиций, реакцию на ошибку/успех и порог освоения.
`AnimalProgressTest` — звёзды, точность и переход животного в «освоено».
`EchoTargetTest` — приоритет явного выбора животного и безопасные фолбэки.
`EchoFilesTest` — очистка временных записей «Эхо».
`WavDurationTest` — длительность WAV по заголовку и пауза перед названием
животного (плюс проверка, что у всех звуков в assets она правдоподобная).
`CatalogJsonTest` парсит настоящий `catalog.json`, проверяет уникальность id,
наличие каждого файла в `assets/`, заполненность ласковых имён, а также что
все PNG — 1024×1024 с альфа-каналом (ловит опечатки и битые картинки до
запуска на устройстве). `AnimalNarrationNameTest` — выбор ласкового имени
для TTS и откат на каноническое название, если поле пустое.
`GuessSessionTest` — после верного ответа игра показывает подсветку и уходит
в следующий раунд, а последняя победа сразу открывает награду: похвалу играет
она, и файл не звучит дважды подряд.
`SpeechRetryPolicyTest` — ожидание поднимающегося синтезатора речи
ограничено тремя секундами, а не длится бесконечно.
`SpotlightPolicyTest` — сколько крупный план висит минимум (2,5 с, чтобы
короткий звук не мигал), как он следует за длиной записи и сколько ждать
фразу TTS, если колбэк не придёт.
`AnimalCloseUpOnomatopoeiaTest` — подпись «Му-у-у!» берётся из каталога,
откатывается на короткое «Му» и не превращается в пустую строку.
`AnimalImagesTest` — размер кэша иллюстраций (восьмая часть кучи с
границами 8…64 МБ) и приведение пути из каталога к имени файла в `assets`.
`EchoPlaybackTest` — что происходит с прослушиванием записи при смене
аудиофокуса: постоянная и временная потеря (включая приглушение) останавливают
звук и один раз сообщают UI, возврат фокуса ничего не перезапускает, а
завершение после потери не гасит «Играет…» второй раз.
`GuessCardSemanticsTest` — что читает TalkBack на карточке: имя отдельно от
действия, «Верно» / «Не то, попробуй ещё» только после нажатия.

Android-обёртки (`MediaPlayer`, `AudioManager`, семантика Compose) тестами не
покрыты — им нужен эмулятор или Robolectric, а проект собирается офлайн без
этих зависимостей. Поэтому решения вынесены в чистые классы (`EchoPlayback`,
`AudioFocusHold`, `guessCardSemantics`, `imageCacheBytes`), а в обёртках
остались только вызовы API.

```bash
./gradlew testDebugUnitTest
# отчёт: app/build/reports/tests/testDebugUnitTest/index.html
```

## Проверка на эмуляторе

Ручные сценарии и скриншоты для стора снимаются на AVD `whosayswhat`
(Android 15, `google_apis`, x86_64). Если system image ещё не установлен:

```bash
SDK=~/Library/Android/sdk
$SDK/cmdline-tools/latest/bin/sdkmanager "system-images;android-35;google_apis;x86_64"
$SDK/cmdline-tools/latest/bin/avdmanager create avd -n whosayswhat \
  -k "system-images;android-35;google_apis;x86_64"      # один раз, если AVD нет
$SDK/emulator/emulator -avd whosayswhat -no-window -no-audio -gpu swiftshader_indirect &
./gradlew installDebug   # или adb install -r app/build/outputs/apk/debug/app-debug.apk
```

В этом AVD выставлен `wm size 1080x1920` при плотности 420 — ровно как у
скриншотов 16:9, поэтому координаты тапов в сценариях ниже пересчитывать не
нужно. `-no-audio` годится для скриншотов и проверки UI: запись в «Эхо»
работает, но звук в headless-режиме не услышать.

Что прокликано вживую:

- три нажатия по замку → панель «Для родителей»; короткий Back панель не
  открывает;
- тап по карточке в песочнице → звук, пауза и тёплая фраза «Это слоник!»
  (системный Google TTS, в логах видно запрос `ru-RU`; речь замедлена,
  чтобы название звучало почти по слогам; ласковое имя — из поля
  `affectionate_name`); быстрое переключение карточек отменяет предыдущее
  название, уход в игру — тоже;
- новые карточки в конце песочницы (курица, волк, медведь, ворона, кукушка,
  слон) — на месте, тап запускает звук и название; в `dumpsys audio` видны
  TTS-сессии с `CONTENT_TYPE_SPEECH`;
- «Выйти» на песочнице → диалог «Выйти из игры?»; «Остаться» возвращает в
  игру, «Выйти» вызывает `finishAndRemoveTask()` (задача исчезает из недавних);
- Back: диалог «Эхо» закрывается, награда и игра возвращаются на песочницу,
  на песочнице не делает ничего (activity не закрывается).

Что остаётся ручным (в юнит-тестах проверена только логика решения, не сами
сервисы Android):

- **Потеря аудиофокуса.** Записать «Эхо», нажать «Послушать» и во время
  прослушивания запустить таймер, чтобы он забрал звук:
  `adb shell am start -a android.intent.action.SET_TIMER -e android.intent.extra.alarm.LENGTH 5`
  (или включить музыку в другом приложении). Ожидаемо: запись замолкает,
  «Играет…» гаснет, кнопка снова «Записать». Правило «кто кого уведомляет»
  закреплено `EchoPlaybackTest`, здесь проверяется сам `AudioManager`.
- **TalkBack.** Включить в настройках доступности (или
  `adb shell settings put secure enabled_accessibility_services com.google.android.marvin.talkback/com.google.android.marvin.talkback.TalkBackService && adb shell settings put secure accessibility_enabled 1`)
  и пройти раунд: карточка читается как «Корова, кнопка, Выбрать», после
  нажатия звучит «Верно» или «Не то, попробуй ещё», эмодзи не читаются.
  Тексты и условия объявления закреплены `GuessCardSemanticsTest`.
- **Крупный план.** Тап по животному в песочнице открывает увеличенную
  карточку: звук играет сразу, название — голосом синтезатора, окно
  закрывается само за 2,5–6,5 с. Повторный тап по карточке повторяет звук,
  тап по затемнённому фону и Back возвращают к животным. Для TalkBack
  карточка — одна кнопка «Корова. Му-у-у!», а фон в дерево не попадает:
  `adb shell uiautomator dump` должен показать единственный кликабельный
  узел с этим `content-desc` и ни одного отдельного «Корова» / «Му-у-у!».
